# CCL Quarantine

This directory stores only sanitized metadata about claims or artifacts excluded from normal publication or decision flow.

Quarantine reasons may include:

- missing provenance;
- stale-head evidence;
- schema failure;
- contradictory results;
- incomplete benchmark environment;
- impossible values;
- unsafe personal or operational data;
- credential-like content;
- unresolved public-safety finding.

Raw dangerous values are not copied here. A public quarantine record identifies the rule or reason, states that the raw value is not stored, and describes the safe resolution path.
