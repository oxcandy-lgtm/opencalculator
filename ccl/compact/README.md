# CCL Compact Views

This directory is reserved for deterministic compact projections of canonical CCL data.

A compact view:

- identifies its source records and generator version;
- never becomes independent authority;
- is regenerated rather than hand-maintained;
- preserves status labels such as canonical, experimental, unverified, rejected, and quarantined;
- does not omit a known failure in a way that changes the meaning of the source state;
- remains subject to the public-safety scanner.

No compact generator is claimed as implemented yet.
